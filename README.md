# 四平台视频发布文案 Skill

这是一个用于 Codex 的中文短视频发布文案 Skill。它会根据视频主题、脚本或素材信息，为以下四个平台分别生成可直接发布的标题、描述和标签：

- 抖音
- 小红书
- 视频号
- B 站

## 适用场景

当你已经有视频或脚本，但需要快速准备多平台发布文案时，可以使用这个 Skill。它会根据平台的内容习惯做差异化表达，而不是把同一段文案复制到四个平台。

## 使用方式

将 skills/video-publish-copy-cn4/ 复制到 Codex 的 Skills 目录：

~~~bash
cp -R skills/video-publish-copy-cn4 ~/.codex/skills/
~~~

然后在 Codex 中直接调用：

~~~text
使用 $video-publish-copy-cn4，根据这条视频的主题或脚本，生成抖音、小红书、视频号和 B 站可直接发布的标题、描述与标签。
~~~

也可以补充视频类型、目标受众、语气、时长、地点或必须保留的信息，让结果更贴合具体内容。

## 默认输出

每个平台都会单独给出：

1. 标题
2. 描述
3. 标签

如果信息不足，Skill 会先基于已有内容作出明确假设，并避免编造视频中没有出现的事实、数据或经历。

## 平台侧重点

| 平台 | 文案侧重点 |
| --- | --- |
| 抖音 | 前置冲突或结果，短句、强节奏、适合快速滑动场景 |
| 小红书 | 真实体验、清单感和可收藏信息，语气更生活化 |
| 视频号 | 更自然、可信、适合熟人关系链传播的表达 |
| B 站 | 信息密度、过程和细节，允许更完整的上下文 |

## 说明

- 本 Skill 只负责生成发布文案，不负责剪辑、封面制作或自动上传。
- 生成结果仍建议结合视频成片、平台审核规则和账号风格进行人工确认。
- Skill 名称：video-publish-copy-cn4
