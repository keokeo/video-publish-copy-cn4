# 四平台视频发布文案

为同一条视频生成可直接发布到抖音、小红书、视频号和 B站的标题、描述与标签。四个平台共享事实与核心命题，但文案不可简单复制。

## 先锁定主题

优先读取用户提供的最终脚本、成片说明、字幕、项目文件或对话上下文。先用一句话判断：

`这条视频讲的是：……`

标题、描述和标签都必须回扣这句话。只使用输入中有依据的人物、地点、数字、结果和感受，不虚构成绩、冲突、身份或拍摄地点。

如果已有信息足以判断主题，直接产出；只有核心内容无法判断时才询问用户。

## 默认交付格式

默认每个平台提供 1 套最终可发布版本，不先堆砌候选：

```markdown
这条视频讲的是：……

## 抖音
标题：……
描述：……
标签：#…… #……

## 小红书
标题：……
描述：……
标签：#…… #……

## 视频号
标题：……
描述：……
标签：#…… #……

## B站
标题：……
描述：……
标签：关键词、关键词、关键词
```

用户要求候选时，再为每个平台提供 3–5 个标题，并明确推荐 1 个。用户要求落盘时，将最终四平台文案写入其指定文件；未指定文件时，不自动修改项目。

## 平台适配

### 抖音

- 标题先给冲突、反差、结果或强场景，口语化，两段式优先。
- 描述短而有节奏，前两行说清看点，避免长背景说明。
- 默认 5–7 个标签：主题、场景、地点、垂类、生活方式；不堆无关热词。
- 数字真实且有吸引力时，可以前置。

### 小红书

- 标题兼顾搜索词与个人体验，通常使用“关键词｜感受或结果”的结构。
- 描述像真实笔记：交代场景、过程、数据或心得，分段清楚，可直接复制。
- 默认 6–9 个标签，覆盖地点、垂类、场景、经验和生活方式。
- 可以使用一个克制的 emoji，但默认不强加。

### 视频号

- 标题清楚、完整、可信，适合熟人社交与转发，少用夸张悬念。
- 描述强调经历、感受和意义，语气自然成熟，不写成营销话术。
- 默认 3–5 个高相关标签。
- 可以比抖音多说一句背景，但不要写成长文。

### B站

- 标题可容纳更多信息，明确场景、过程或结果，兼顾搜索与叙事。
- 描述补充背景、关键数据、视频看点和结尾判断，适合简介区阅读。
- 默认 6–10 个站内关键词，以中文顿号或逗号分隔，不强制加 `#`。
- Vlog、教程、测评等类型词只有在内容确实匹配时才使用。

## 质量检查

提交前检查：

- 四个标题都命中同一核心主题，但表达角度符合各平台。
- 前半句有明确点击理由，后半句提供方向、结果或感受。
- 标题没有把视频内容完全说尽，也没有制造输入中不存在的悬念。
- 描述不是标题的机械扩写，且复制后无需二次整理。
- 标签全部与视频真实内容相关；不使用 `#热门`、`#上热门` 等无意义标签。
- 地点、数字、时间、配速、产品名和人物身份与输入一致。

## 边界

本 Skill 只生成发布文案。不要据此上传视频、发布内容、生成封面或修改成片，除非用户另行明确授权并调用相应能力。
